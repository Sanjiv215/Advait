# 🧘 Advait

> **An AI-powered Yoga Assistant for intelligent conversations and AI image generation.**

Advait is an AI agent designed to help users explore yoga through natural conversations while also generating AI-powered images related to yoga, meditation, wellness, and mindfulness.

---

## ✨ Features

* 💬 AI-powered Yoga Chat Assistant
* 🧘 Answers yoga-related questions
* 🎨 AI Image Generation
* ⚡ Fast and interactive interface
* 🐍 Built entirely in Python
* 🔮 Easily extendable with new AI capabilities

---

## 🛠️ Tech Stack

* Python
* OpenAI API / LLM
* Image Generation API
* REST APIs

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/Sanjiv215/Advait.git
cd Advait
```

### Install dependencies

```bash
pip install -r requirements.txt
```

> If a `requirements.txt` file is not available, install the required libraries manually.

### Run the project

```bash
python Advait.py
```
